## How this inventory was produced

```bash
python3 -c "
import json
from collections import defaultdict
d = json.load(open('harness_v19/llm_names.json'))
by_image = defaultdict(list)
for k, v in d.items():
    img, addr = k.split('|', 1)
    by_image[img].append((int(addr, 16), v.get('name'), v.get('subsystem'), v.get('docstring', '')[:80]))
# ... iterate and print
"
```

## Regenerate

The `llm_names.json` is regenerated by:
- `harness_v17/naming_batch.py` (LLM tool-use, requires API keys)
- `fwstruct names --llm-key-dir <dir>` (Go-based alternative)
