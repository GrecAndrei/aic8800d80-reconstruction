# AIC8800D80 Firmware Decompilation Dataset (v15)

## Description

A dataset of 54,685 (function, arm_thumb, behavioral_c) tuples extracted from
production AIC8800D80 WiFi/Bluetooth chip firmware. Each tuple contains:

- `function`: function name (e.g., `buffer_pool_get`)
- `image`: source firmware binary (fmacfw_8800d80_h_u02, fmacfw_8800d80_u02, fmacfwbt_8800d80_u02, or lmacfw_rf_8800d80_u02)
- `address`: function entry point in v14 user-space addressing
- `chip_address`: function entry point in chip runtime addressing
- `arm_thumb`: ARM Thumb-2 disassembly of the function (first 30 instructions)
- `behavioral_c`: behavioral C reconstruction generated by Unicorn trace replay
- `mmio_op_count`: number of MMIO operations captured in the trace

The `behavioral_c` field contains mechanical C code that captures the side
effects (MMIO loads/stores) of the original function, verified against the
actual trace data via a strong verifier.

## Use cases

- Training decompiler models (ARM Thumb → C)
- Studying firmware behavior patterns
- Reverse engineering tool benchmarking
- Embedded systems research

## Provenance

Source firmware: `inputs/firmware/*.bin` (4 binaries, ~1.2MB total)
Source commit: 8a88b52 (v15 release)
Build date: 2026-06-13
Method: Unicorn emulator + behaviorsynth (Go)

## Format

JSONL with one record per line. Each record is a JSON object with the
fields listed above. The `arm_thumb` and `behavioral_c` fields are strings
containing the disassembly / C code.

## Limitations

- Behavioral C captures side effects, not source semantics
- 10,015 high-level dispatchers (interrupt handlers, state machine
  dispatchers) are NOT included - v14 pipeline could not trace them
  because they don't directly touch MMIO
- LLMs are NOT used to translate ARM assembly - all C is mechanically
  generated from Unicorn traces
- Some functions may have cosmetic artifacts from the Go synth tool

## Reproducibility

To reproduce this dataset:

1. Get the AIC8800D80 firmware binaries
2. Run the v14 pipeline (`tools/run_behavioral_gen.py`)
3. Score with strong verifier (`tools/score_truth_lane_v15.py`)
4. Build the index (`/tmp/build_dataset.py`)
5. Pair with r2 disasm (`/tmp/build_disasm_dataset_v4.py`)

All scripts are in the repository under `tools/`, `harness_v15/verifier/`,
and `/tmp/`.
