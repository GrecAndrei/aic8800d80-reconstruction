# v15 Final Summary

## What we built

A 54,685-record dataset of verified behavioral C function reconstructions
from real production WiFi chip firmware (AIC8800D80). Each record pairs
ARM Thumb-2 disassembly with a behavioral C body that was generated by
tracing the original function through the Unicorn emulator.

## Key methods

### 1. Strong verifier (the gate)
- `harness_v15/verifier/verify.py`
- Rejects v13 behavior_lift templates
- Two acceptance paths:
  - **Leaf**: 0 BL targets + real register/MMIO ops → PASS
  - **Calling**: ≥1 callee matches real BL target in r2 disasm → PASS
- Register-name filter excludes `blx r0-r15` from named BL

### 2. Behavioral trace replay (source of truth)
- v14 pipeline: Unicorn emulator at BASE=0x1200000
- Trace each function entry, capture every MMIO load/store
- Go binary `behaviorsynth` converts trace JSON to mechanical C:
  ```c
  *((volatile uint32_t *)(uintptr_t)0xADDR) = val;
  (void)*((volatile uint32_t *)(uintptr_t)0xADDR);
  ```

### 3. Integration (O(n) text splice)
- `tools/integrate_v15.py`
- Replaces TODO stubs in composed C with behavioral bodies
- Single-pass list-join splice (NOT `replace()` in loop)
- 39,045 stubs replaced in 47.5s across 4 binaries

## Two paths forward

### Path A: Publishable dataset ✅
- 54,685 records with `arm_thumb` ↔ `behavioral_c` pairs
- Ready for HuggingFace upload
- Useful for training decompiler models

### Path B: Runnable replacement (not achievable in v15)
- Compiles to ARM cleanly ✓
- BUT 10,015 TODO stubs remain (interrupt handlers, dispatchers)
- BUT no init/boot code reconstructed
- Would require LLM-assisted decompilation of high-level dispatchers
- This is a research-grade artifact, not a runnable replacement

## What changed in v15

1. **Address scheme fix**: truth_lane_targets.json used RUNTIME addr for fmacfw_h
   (base 0x100000) but FILE OFFSET for other 3 binaries. Converted all 6
   missing functions to use `0x1200000 + file_offset` to match the v14
   pipeline's BASE.

2. **Strong verifier improvements**:
   - Register-name filter: excludes r0-r15, sl/fp/ip/sp/lr/pc from BL
   - Anonymous function detection: treats fcn.0x... and sub_ as anonymous
   - Fast mode: 10-30x speedup via r2_disasm(analyze=True/False)

3. **Bulk pipeline**: scaled from 138 manual samples to 54,685 (396x)
   using ThreadPoolExecutor per-image, 90.1% success rate

4. **Brace bug fix** (the killer one):
   - sig calculation was off-by-one, producing "void fn(void) {{" output
   - Fix: pass open_brace_pos from find_function_blocks
   - All 4 integrated files: 0 brace diff, 0 double-braces

5. **ARM compilation**: 0 errors on all 4 binaries, 5,432 benign warnings
